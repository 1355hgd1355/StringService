# Добро пожаловать!

Это телеграм-бот, который может присылать новости. Он присылает новости с учётом выбранных источников и тегов. Позволяет настраивать интервал и кол-во новостей.

# Как использовать телеграм-бот?
```
/start - начать работу
/sources - управление источниками
включить [Название] - включает источник
выключить [Название] - выключает источник
/tags - управление тегами
добавить тег [Название] - добавляет тег
удалить тег [Название] - удаляет тег
новый тег [Название] - позволяет создать новый тег
/settings - настройки (интервал, количество новостей)
интервал [число от 5 до 1440] - настраивает время сканирования новостей
количество [число от 1 до 10] - количество показываемых новостей
/help - помощь
```
